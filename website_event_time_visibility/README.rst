========================================
Website Event: Optional Time Visibility
========================================

* Adds a "Show Time on Website" toggle to the event form
* When disabled, the event page and registration confirmation page on the
  website only show the start/end dates, not the time of day. The timezone
  is still shown, as it is not tied to the time of day.
* Useful for e.g. self-paced online courses that start at a specific time
  but have no fixed end time of day
* Enabled by default, so existing events keep showing the time of day as
  before

Configuration
=============
* In the event form, next to the date fields, toggle "Show Time on Website"

Usage
=====
* Open an event page on the website to see the effect: with the toggle
  disabled, only the dates are shown in the "Date & Time" sidebar block and
  on the registration confirmation page
