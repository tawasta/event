================================
Event Remove Translatable Fields
================================
* Remove translate attribute from Event fields.

  * Event template: name
  * Event: name and description
  * Event ticket: name and description

On install the existing values are converted to plain text columns. Only the
English (en_US) value of each field is kept, translations in other languages
are lost.
