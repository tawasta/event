========================================================================
Website Event Cancellation: E-mails Show Responsible Person Contact Info
========================================================================

* Modifies the website_event_cancellation module's e-mail templates so 
  that instead of the organizer, the responsible person's contact info 
  gets shown

Configuration
=============
* None needed

Usage
=====
* Just set the Responsible person for an event, and send out one of the 
  event e-mails
