=================================================
Website Event: Show 'Sales Start' Info for Events
=================================================

* Show ticket sale start date in frontend event listing
* In case of multiple ticket types, the earliest Sales Start date is shown
  (the event's "Start sale date" of Odoo core)

Configuration
=============
* Add a ticket type to an event

Usage
=====
* Just navigate to /event to see the registration start date on each event
