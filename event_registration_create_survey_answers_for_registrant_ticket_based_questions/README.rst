========================================================================================
Event Registration: Create Survey Answers for Registrant - Ticket Based Question Support
========================================================================================

* Enables the ticket specific question feature also when 
  answering on behalf of registrant
* A glue module between survey_question_show_only_for_specific_event_ticket and
  event_registration_create_survey_answers_for_registrant

Configuration
=============
* None needed

Usage
=====
* Launch the survey answering wizard from event registration form, for a registration
  that is buying a ticket that some questions specified.
