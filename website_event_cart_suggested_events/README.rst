===================================
Website Event Cart Suggested Events
===================================

This module allows related events to be promoted in the webshop cart when a
customer has selected an event ticket.

The promoted events are configured directly on the event form. They are shown in
the cart as marketing suggestions with a link to the event registration page.

Suggested events are not added to the cart automatically.

Configuration
=============

#. Go to **Events > Events**.
#. Open an event.
#. Go to the **Suggested Events** tab.
#. Select the events that should be promoted in the cart when this event is in
   the customer's cart.

Usage
=====

#. Add an event ticket to the cart from the website.
#. Open the webshop cart.
#. Related suggested events are displayed below the cart content.
#. Click **View event** to open the suggested event registration page.
