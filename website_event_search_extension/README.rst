==============================
Website Event Search Extension
==============================

This module extends the Odoo Website Event search functionality by including
the event description field in website search queries.

By default, Odoo Website Event searches event records using a limited set of
fields such as the event name and subtitle. This module adds the event
``description`` field to the search definition, allowing website visitors to
find events based on content stored in the event description.

Configuration
=============

No configuration is required.
