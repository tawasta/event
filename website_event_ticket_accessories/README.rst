================================
Website Event Ticket Accessories
================================

This module extends the event ticket sales flow on the website by allowing
accessory products to be linked to event tickets.

When a customer adds an event ticket to the cart, the configured accessory
products are automatically suggested in the webshop cart. Before proceeding
to checkout, the customer is redirected back to the cart once to review the
available accessory products.

The module helps increase accessory sales related to event participation,
such as printed materials, merchandise, meals, parking products, or other
event-specific add-ons.

Configuration
=============

#. Go to **Events > Events**.
#. Open an event and edit its tickets.
#. For each ticket, configure the **Accessory Products** field.
#. Select one or more saleable products that should be suggested together
   with the ticket.

Usage
=====

#. Open the website shop.
#. Add an event ticket to the cart.
#. Navigate to the cart page.
#. Any accessory products configured for the selected ticket are displayed
   among the suggested products.
#. Proceed to checkout.
#. If accessory products are available and have not yet been reviewed,
   the customer is redirected to the cart once before checkout.
