=========================================================
Website Event Track: Show Menu Without Technical Features
=========================================================

* Show the 'Tracks' menu to event users without developer mode

Configuration
=============
* None needed

Usage
=====
* Just view the Events main menu without Technical Features rights.

Known issues / Roadmap
======================
* Note that uninstalling the module does not remove the added groups from the menu,
  this needs to be done manually if needed.
