===========================
Website Event Publish Event
===========================

Makes publishing an event on the website easier. Adds a *Published* toggle to
the event form and an action to publish many events at a time, and keeps the
publishing of an event together with its stage.

Configuration
=============

Mark the stages that mean that an event is published with *Published Stage* on
the event stage. The stage *Announced* is marked by default. If there are many,
the first one by sequence is used.

Usage
=====

* Toggle *Published* on the event form, next to *Visibility*: the event is
  published and moved to the first published stage.
* Move an event to a published stage: the event is published.
* Select events in the list, open the actions and choose *Publish events on
  website*. The action is for event managers.
