============================================
Event Registration Button Text Customization
============================================
This Odoo module allows you to customize the **"Go to Payment"** and **"Confirm Registration"** button texts on the event registration form based on Website settings.

Features
============
- Add translatable custom text for:
  - Payment button ("Go to Payment")
  - Registration button ("Confirm Registration")
- Fallback to core default texts if no value is set

Configuration
=============
Go to **Website Settings** and fill in:

- *Event Payment Button Text*
- *Event Registration Button Text*

Leave either blank to use Odoo's default core label.

Usage
=====
1. Go to *Website → Configuration → Settings*
2. Enter your custom button labels under the **Registration settings**
3. Save the settings
4. Go to an event and register — your labels will be used
