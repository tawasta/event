Event Registration Limitations
==============================

* Restricts the event registrations per test type, so that a user cannot register
  the same dog for the same type of test again before the evaluation.
* On the event registration page the registration is hidden and a notice is shown
  when the user has no dogs or all the dogs are already registered for the test
  types of the event.
  Events with several time slots hide the "View More" registration button too.
* When a registration is confirmed, the user's other unconfirmed registrations
  of the same dog and test type are cancelled.
* While the registration is not open, the page does not show the planned start
  date of the ticket sales, only that the registrations are not open yet.
