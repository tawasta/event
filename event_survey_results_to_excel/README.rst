=============================
Event Survey Results to Excel
=============================

This module adds a "Print Event Answers to XLSX" report to event
attendees, exporting their registration question answers to an Excel
file.

The report has one row per attendee and one column per event question.
All selected attendees must belong to the same event.

Configuration
=============
\-

Usage
=====

#. Go to **Events > Registrations**.
#. Select one or more attendees belonging to the same event.
#. Click **Print > Print Event Answers to XLSX**.
#. The downloaded file has one row per attendee and one column per
   question, with the attendee's answer in each cell.
